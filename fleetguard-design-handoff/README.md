# FleetGuard — Design Handoff

Gói này tổng hợp các nội dung thiết kế đã cung cấp trong cuộc trò chuyện:
- Design system và component inventory
- Color tokens
- Font, typography scale
- Spacing, radius, shadow
- Icon và illustration guidance
- Section outline và nội dung giao diện
- Prompt tái tạo hình ảnh
- Gợi ý tổ chức file Figma
- Ảnh mockup/component sheet (nếu có trong gói)

## Nội dung
- `design-system.md`: tài liệu thiết kế chi tiết bằng tiếng Việt
- `tokens.json`: token màu sắc, typography, spacing, radius, shadow ở dạng dữ liệu
- `prompt.txt`: prompt đầy đủ để tạo mockup hình ảnh
- `assets/`: ảnh tham chiếu được đóng gói

## Lưu ý
Đây là handoff thiết kế dựa trên ảnh mockup, không phải file Figma gốc và không bao gồm mã website. Các giá trị màu, cỡ chữ và số liệu trên giao diện là token đề xuất hoặc nội dung hiển thị trong mockup; cần xác minh trước khi sử dụng chính thức.
